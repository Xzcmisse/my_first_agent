1. 框架的两大价值：自动微分 + GPU
- 自动微分（autograd）：框架会自动记录你所有运算，然后自动算出每个参数的梯度 —— 你不用再手写 dw、db。你昨天手写 dw = (2*(y_pred-y)*x).mean() 就是"手动微分"；PyTorch 里一句 loss.backward() 全搞定，哪怕网络有 100 层。
- GPU 加速：深度学习全是海量矩阵运算，GPU 几千个核心并行算，比 CPU 快几十倍。你昨天 numpy 跑在 CPU；PyTorch 一行 .to('cuda') 就上你的 4060。
- 🎤 一句话：框架把"算梯度"和"上 GPU"这两件最累最慢的事自动了。


2. 低级 API vs 高级 API（一句话）
- 低级 API（PyTorch / TensorFlow）：给你零件（张量、自动微分、优化器），结构自己搭、训练循环自己写 → 灵活、可控，研究/学习用。
- 高级 API（PyTorch Lightning / Keras）：常见流程都封装好，你主要写"模型结构 + 数据"，训练循环它帮你转 → 省事、样板少，快速做产品用。
- 🎤 一句话：低级给你自由，高级给你省事；两者能混用。


3. 防过拟合 4 招
1. 增加训练数据（最有效 —— 加的是信息）
2. 降低模型复杂度（换更小/更简单的模型）
3. 正则化（如 Dropout：训练时随机"关掉"部分神经元，逼模型别依赖个别特征）
4. 早停（验证误差回升前停下）
- 🎤 一句话：过拟合要"减"——减复杂度、减训练（早停）、加约束（正则化），最好再加点数据。


4. 偏差-方差权衡
- 偏差（bias）大 = 模型假设太简单，抓不住规律 → 欠拟合（训练差、验证也差）。
- 方差（variance）大 = 模型对训练数据太敏感，把噪声也学了 → 过拟合（训练好、验证差）。
- 权衡：模型越复杂 → 偏差↓ 但方差↑；越简单 → 偏差↑ 但方差↓。目标是让 总误差（≈ 偏差² + 方差 + 噪声） 最小，找那个"刚好"的复杂度。
- 🎤 一句话：欠拟合是偏差大，过拟合是方差大；模型别太简单也别太复杂，找中间那个刚好。


5. 为什么要分 训练集 / 验证集 / 测试集
- 训练集：学参数（调 w、b）。
- 验证集：调超参 + 早停 + 选模型（用"没见过"的数据判断真会与否）。
- 测试集：最后只用一次，出"最终成绩"。
- 为什么测试集必须独立：如果你反复拿验证集调，你迟早会"连验证集都调过拟合了"（信息泄漏）→ 所以要留一份从没参与过任何决策的数据来给最终评价。
- 类比：训练集=平时作业，验证集=平时小测（查漏补缺、调整学习策略），测试集=期末考（只能考一次，成绩才真实）。
- 🎤 一句话：训练集学、验证集调、测试集考；测试集必须"考一次就完"，否则成绩不可信。
