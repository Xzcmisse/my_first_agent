2. 四拍（每一批数据都走一遍）
   - 前向 `y_pred = model(X)`：学生做例题，先答一版
   - 损失 `loss = loss_fn(y_pred, y)`：尺子/裁判，打出"错得多离谱"的分
   - 反向 `loss.backward()`：老师批改，指出每个 w、b 该往哪调、调多少
   - 更新 `optimizer.step()`：照着批改写笔记，参数真的动了
   - 前面还有 `optimizer.zero_grad()`：换一张白纸，清掉旧梯度（梯度是累加的，不换就新旧账混在一起）
3. lr 就是步幅：太大发散，太小磨蹭，1e-3 是甜点；1e-3 = 0.001

## 今天跑出来的实验结论
| 改动 | 结果 | 结论 |
|---|---|---|
| range(3) → range(4) | acc 0.9695 → 0.9725 | 多练一轮小涨 |
| 隐藏层 128 → 64 | 参数量 101770 → 50890，acc 0.9609 | 参数砍掉一半，精度只掉 0.9% |
| 隐藏层改 16 | 报错 mat1 64x16 vs 128x10 | 改一层的"出"必须同步改下一层的"入"（@ 内维要相等） |
| lr = 1e-4 | acc 0.9278 | 太小，学得慢 |
| lr = 1e-6 | acc 0.5867，loss 卡在 2.2 | 几乎没学（2.3 才是瞎猜水平） |
| lr = 1e-1 | acc 从 0.82 掉到 0.76 | 太大，震荡倒退 |
| lr = 5 | 第一轮 loss 216，之后卡 2.56，acc 10% | 发散/爆炸；练多少轮都没用，只能调小重新训练 |
| 删掉 ReLU | acc 卡在 0.9228 上不去 | 无激活 → 深层退化成一层线性（欠拟合） |

新术语：发散(divergence) / 收敛(convergence)；欠拟合 vs 过拟合
