# 2026-10-17（第 3 周 D1-D2：RAG 检索）

## 今天学会了什么
1. RAG = **先检索、再生成**。今天只做检索，不接大模型
   - 微调 = 闭卷（数据进模型参数，要重训）；RAG = 开卷（数据进向量库，模型不动，加文档秒级）
2. 五步流程，且分成"离线 / 在线"两段
   - 离线：文档 → 切块 → 向量化 → 建索引（只做一次）
   - 在线：问题 → 向量化 → 索引里搜 top-k → 取回原文（每次提问）
   - 通俗：离线 = 把书架整理好，在线 = 查目录翻书
3. 五个关键词
   - chunk（块）：文档切成小段，一块只装一条信息
   - embedding（向量）：一段文字 → 512 个数字，语义近则数字近
   - 相似度：向量内积（归一化后 = 余弦相似度）
   - top-k：取最像的 k 条
   - 索引：FAISS 里的向量库，负责快速找最近邻
4. 技术栈（已装好）
   - faiss-cpu 1.15.1
   - sentence-transformers 6.1.0
   - 模型 BAAI/bge-small-zh-v1.5（512 维，已缓存，不用再下）
   - 语料：自己的 notes/*.md
5. 为什么要切块：一段话太长会被"平均"成一个向量，主题被冲淡；一块一条信息，检索才准
6. 问题必须用**同一个模型**编码：文档和问题用不同模型 → 向量空间对不上，等于鸡同鸭讲

## 还没解决的：词表鸿沟
同一件事换个说法就搜不到：
| 问法 | 结果 |
|---|---|
| 「学习率太大…」 | ❌ 返回偏差 / 方差 / 训练集 |
| 「lr 太大…」 | ✅ 命中 `lr = 1e-1 | acc 0.82→0.76 | 太大，震荡倒退` |
| 「学习率 learning rate lr 太大…」 | ✅ 命中「步长由学习率 η 控制」 |

原因：笔记里写的是 `lr`，提问写的是「学习率」，小模型没把两个词连起来。

## 还发现一个小坑
节标题前缀是双刃剑：帮模型知道"这段属于哪节"，但同节的块会互相扎堆抢位置（top1 出现了同节但不相关的「一堆函数名还不认识」）。
